# 오늘의 태클 조합 🎣

내 태클 세팅·루어·자주 가는 필드를 저장해두면, 그날 날씨와 현장 조건에 맞춰
**어떤 태클을 챙겨서 어느 포인트를 무엇으로 공략할지** 추천해주는 웹앱입니다.

설치나 빌드가 필요 없는 정적 웹앱(HTML/CSS/JS)이고, 서버도 필요 없습니다.

## 실행

```bash
git clone https://github.com/kwangorithm/tackle-combo && cd tackle-combo
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages, Netlify 같은 정적 호스팅에 이 저장소를 그대로 올리면 휴대폰에서도 쓸 수 있습니다.
휴대폰 브라우저에서 "홈 화면에 추가"를 누르면 앱처럼 실행됩니다(PWA).

## 기능

| 탭 | 내용 |
|---|---|
| 오늘 | 필드·날짜(7일)·시간대를 고르면 날씨를 불러와 상위 3개 조합(메인/서브/비장의 카드), 추천 포인트, 운용 액션, 추천 근거, 컬러 가이드, 패킹 체크리스트를 보여줍니다 |
| 태클 | 로드+릴+라인 세팅과, 그 세팅으로 쓰는 루어 카테고리 |
| 루어 | 카테고리, 보유 컬러, 나만의 운용법 메모, ★ 자신 있는 루어(우선 추천) |
| 필드 | 대형지/유료터, 평소 물색, 좌표, 포인트별 구조물 태그 |
| 백업 | JSON 내보내기/가져오기(기기 이동), 기본 데이터로 초기화 |

처음 실행하면 이동지·고삼지·미산지·신원지·신기지와 마스터 테이블의 장비 8세트·루어 12종이 기본으로 들어 있습니다.
**필드 좌표는 대략값이니** 필드 탭에서 정확히 고치거나 현장에서 "📍 지금 위치로 좌표 채우기"를 누르세요.

## 추천 방식

1. **날씨** — [Open-Meteo](https://open-meteo.com/)(무료, API 키 없음)에서 시간대별 기온·하늘·풍속·기압을 가져옵니다.
   - 기압 추세: 24시간 전 대비 ±2hPa
   - 수온(추정): 직전 7일 평균 기온 + 계절 보정(가을 +2.5, 봄 −1.5 등)
   - 물색: 필드 평소 물색에서 최근 3일 강수량(10mm/30mm 이상)만큼 탁하게 보정
   - 날씨를 못 불러오면 계절 평균값으로 계산하고, "현장 조건 직접 조정"으로 수온·물색 등을 덮어쓸 수 있습니다.
2. **카테고리 점수** — 10개 루어 카테고리(탑워터, 팝퍼, 미노우, 무빙, 크랭크, 바닥 웜, 헤비커버, 수직 피네스, 미드스트롤링, BFS)마다
   수온·하늘·바람·기압·시간대·물색·필드 유형에 대한 가중치가 있고, 합계로 순위를 매깁니다. 카드 아래 칩이 점수 근거입니다.
3. **조합** — 상위 카테고리마다 보유 루어(★ 우선), 그 카테고리를 담당하는 태클(전용 세팅 우선), 구조물 태그가 맞는 포인트를 짝지어줍니다.
   좋은 날인데 보유 루어가 없는 카테고리는 "장비 보강 힌트"로 알려줍니다.

가중치는 `engine.js`의 `CATEGORIES`에서 바로 고칠 수 있습니다.

## 데이터 저장

모든 데이터는 브라우저 `localStorage`에만 저장됩니다(서버 전송 없음). 브라우저 데이터를 지우면 사라지니 가끔 백업 탭에서 내보내기 해두세요.
